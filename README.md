# MiVitrina - Cliente (Landing Page Generator)

**MiVitrina** es una plataforma pensada para que emprendedores y startups puedan crear su propia landing page sin conocimientos técnicos. A través de un formulario simple, los usuarios ingresan la información de su negocio y generan automáticamente una página web moderna y responsiva.

Este repositorio contiene el frontend de la aplicación, desarrollado en **React**, encargado de brindar la interfaz visual para el registro de datos, la vista previa y la generación de la landing page.

---

## 🚀 Características

- **Formulario intuitivo**: Los usuarios ingresan datos clave de su negocio como nombre, logo, contacto, productos, redes sociales, etc.
- **Generación automática de landing page**: A partir del formulario, se crea una página con diseño predefinido.
- **Diseño responsivo y atractivo**: Pensado para mostrar profesionalmente la información del local en cualquier dispositivo.
- **Sin necesidad de saber programar**: Todo se hace desde una interfaz amigable.
- **Integración con backend**: Guarda y recupera la información de cada landing desde la base de datos.

---

## 🛠️ Tecnologías Utilizadas

- **React**
- **Tailwind CSS**
